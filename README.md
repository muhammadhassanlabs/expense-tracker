# 💰 Expense Tracker

A simple Python-based Expense Tracker that allows users to record, categorize, and analyze their expenses through a command-line interface.

## 📖 Project Overview

This project was created to practice Python data structures, loops, conditional statements, exception handling, and basic data analysis.

The program allows the user to enter multiple expenses and generates a final report showing the total amount spent, highest expense, and category-wise spending.

## ✨ Features

- ➕ Record multiple expenses
- 🏷️ Categorize expenses
- 💰 Calculate total spending
- 📊 Find the highest expense
- 📋 Display all recorded expenses
- 📌 Generate category-wise expense summary
- ⚠️ Handle invalid input

## 🗂️ Expense Categories

The program supports four categories:

1. Food
2. Transport
3. Education
4. Others
